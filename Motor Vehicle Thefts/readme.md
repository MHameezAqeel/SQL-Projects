# Motor Vehicle Thefts in New Zealand: Data Analysis Project

## 🚗 Project Overview

This data analysis project explores motor vehicle theft patterns in New Zealand, providing insights into temporal, spatial, and vehicle-specific trends from 2021-2022.

## 📊 Objectives

- Identify temporal patterns of motor vehicle thefts
- Determine spatial distribution of vehicle thefts
- Investigate most commonly stolen vehicle types

## 🛠 Tech Stack

- MS SQL Server
- Microsoft Excel
- Statistical Analysis

## 🔍 Dataset Characteristics

- **Period:** 2021-2022
- **Source:** Proprietary database via Maven Analytics
- **Variables:** Unique ID, Vehicle Type, Colour, Date Stolen, Location

## 📈 Key Findings

### Theft Trends
- **73% increase** in vehicle thefts from 2021 to 2022
- More thefts occur on **weekdays** compared to weekends

### Most Stolen Vehicle Types
1. Stationwagon (945 thefts)
2. Saloon (851 thefts)
3. Hatchback (644 thefts)

### Regional Insights
- Highest total thefts: Auckland (1,638 vehicles)
- Highest per-capita theft rate: Nelson

## 🎯 Recommendations

### For Law Enforcement
- Increase patrols in high-risk regions like Nelson
- Focus on weekday prevention strategies
- Prioritize protection of stationwagons and saloons

### For Vehicle Owners
- Enhanced security in high-theft regions (Auckland, Canterbury, Wellington)
- Install anti-theft devices
- Be extra cautious during weekdays

## 🔬 Limitations

- Data covers only 2021-2022
- Relies on proprietary database accuracy
- Regional variations may exist
